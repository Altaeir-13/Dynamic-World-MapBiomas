# Dados preservados

`reference/`: contorno, 337 municípios, estados, suportes 1/5/10km e datas mensais. `processed/`: somente as materializações finais necessárias para recuperar a análise e as exportações canônicas. `audit/`: dois parquets RAW explicitamente históricos para conferir a correção temporal.

Veja [fontes, formatos, volumes, licenças e recuperação](../docs/data.md). Os rasters nacionais não estão incluídos; são obtidos dos catálogos com os IDs documentados. Não são necessários para abrir os resultados já materializados.

Hashes finais: `docs/provenance/release_checksums.csv`. O manifesto original de 33 arquivos permanece em `tables/`. Checkpoints e versões substituídas locais estão fora da seleção pública e aguardam aprovação de limpeza.
